simpletoc via esm.sh

A minimal browser example that loads the package directly from a CDN.

This example intentionally includes a lot of filler content so the table of contents has enough material to navigate and the sticky layout can be tested while scrolling.

Install

No install step is needed when loading from esm.sh. You can reference the package directly from a module script and let the CDN transform the published ESM entrypoint on demand.

Usage

The TOC is generated from the headings in this article. In the default setup, the package queries the content root, builds a normalized heading tree, renders a nested list, and mounts it into the target element.
